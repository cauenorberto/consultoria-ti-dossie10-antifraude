### 1. Papel no projeto

Minha responsabilidade no projeto Escudo 60+ é a estruturação dos pipelines de ingestão de dados em tempo real e a arquitetura de armazenamento seguro das informações.

O objetivo é organizar o recebimento e o armazenamento dos dados gerados pelas transações bancárias, permitindo que essas informações sejam utilizadas na identificação de possíveis fraudes contra pessoas idosas.

Para isso, a proposta considera a utilização de tecnologias como Apache Kafka, que permite transmitir e organizar fluxos de dados em tempo real.

### 2. Principais responsabilidades

- **Ingestão de dados:** estruturar o recebimento de informações relacionadas às transações bancárias, como valores, horários e movimentações via Pix.
- **Processamento em tempo real:** organizar o fluxo de informações para que os dados possam ser encaminhados rapidamente para análise.
- **Armazenamento seguro:** planejar uma estrutura de armazenamento que proteja as informações financeiras e comportamentais dos usuários.
- **Integração:** disponibilizar dados organizados para que a área de Ciência de Dados possa realizar análises e identificar possíveis comportamentos suspeitos.

### 3. Importância da Engenharia de Dados para o projeto

A Engenharia de Dados é fundamental para o funcionamento do Escudo 60+, pois permite que as informações necessárias para identificar possíveis fraudes sejam recebidas, organizadas e armazenadas corretamente.

Com uma estrutura adequada, os dados podem ser utilizados pelos modelos de análise comportamental, contribuindo para a identificação de transações fora do padrão e ajudando na prevenção de golpes financeiros.

Além disso, o armazenamento seguro é essencial para proteger a privacidade dos idosos e evitar o acesso indevido às suas informações.

### 4. Plano de desenvolvimento (SMART)

Meu objetivo é aprofundar meus conhecimentos em Engenharia de Dados, principalmente nas ferramentas utilizadas para processamento de informações em tempo real e armazenamento em nuvem.

**Resultado esperado:** desenvolver conhecimentos práticos que permitam estruturar e organizar fluxos de dados com mais eficiência, ampliando minha preparação profissional para atuar na área de Engenharia de Dados.
